「~x = 5~ と書いたとき、Pythonの内部では何が起きているの?」「なぜPythonでは変数の型を宣言しなくていいの?」――Pythonを学び始めると、なんとなく動くけれど仕組みがよくわからないまま使ってしまいがちなのが「変数」だ。

Pythonはオブジェクト指向プログラミング言語です。

* 変数
変数とは、あるメモリ領域に名前を付けたものである。プログラムのコードからは名前でそのメモリ領域をアクセスすることができる。

Pythonでも他のプログラミング言語と同様、変数を定義できる。Pyhotnで変数を定義するには、変数に値をするだけである。言い換えれば、最初に変数へ値が代入されるときに変数は定義される。

次の例では変数fooを定義している。そして、その変数に値3を代入している。

#+begin_src python
>>> foo = 3
#+end_src

変数にはデータを入れることができるため、変数はデータの入れ物と表現されることがある。ただし、Pythonの場合、変数にデータそのものが入っているわけではない。これについては後述する。

変数の名前は次の規則に従う必要がある。

- 変数名として使用する文字は、小文字・大文字のアルファベット（a〜z、A〜Z）、数字（0〜9）、アンダースコア（_）だけにする。※実際には非ASCII文字なども使用できるが、ここに挙げた文字だけ使用する方が一般的です。
- 先頭の文字はアルファベットがアンダースコアでなければならない。ただし、アンダースコアで始まる名前はPythonでは特別な意味を持つ。
- Pythonの予約語（キーワードともいう）であってはならない。
- 大文字と小文字は区別される。

有効な変数名は次のようなものです。

#+begin_example
name
_name
name1
user_name
_1
MAX_VALUE
#+end_example

次の変数名は有効ではない。

#+begin_example
1name
user-name
class
name!
#+end_example

大文字と小文字は区別されるので、次の変数はすべて異なる名前として扱われる。

#+begin_example
foo
Foo
FOO
#+end_example

* 予約語
予約語とは、プログラミング言語であらかじめ使用が予定されている名前（専門的な用語で識別子という）のことです。予約語はドキュメントを確認するか、Pythonプログラムで次のように確認することができます。

#+begin_src python
>>> help("keywords")
#+end_src

実行した結果は次のとおりです。

#+begin_example
Here is a list of the Python keywords.  Enter any keyword to get more help.

False               class               from                or
None                continue            global              pass
True                def                 if                  raise
and                 del                 import              return
as                  elif                in                  try
assert              else                is                  while
async               except              lambda              with
await               finally             nonlocal            yield
break               for                 not
#+end_example

または、次のようにして一覧を取得することもできる。

#+begin_src python
>>> import keyword
>>> keyword.kwlist
#+end_src

Python 3.10からは=match=・=case=・=_=が、Python 3.12で=type=が「*ソフトキーワード*」として追加された。ソフトキーワードは、=match=文や=type=文といった特定の構文の中でのみ予約語として扱われ、それ以外の場所では通常の変数名として使えるという、少し変わった位置づけの名前だ。ソフトキーワードの一覧は =keyword.softkwlist= で確認できる。

* 代入
Pythonで変数に値を代入するには=を使う。プログラムでの ~=~ は「右辺の値を左辺の変数に代入する」という意味だ。

#+begin_src python
>>> x = 3
>>> x
3
#+end_src

Pythonの変数にはデータ型（単に型ともいう）はない。そのため、どのような型の値でも代入することができる。先ほどの例では整数型（int型）の値を代入していたが、次の例では同じ変数xに文字列型（str型）の値を代入している。

#+begin_src python
>>> x = "Hello"
>>> x
'Hello'
#+end_src

* データ型とは
Pythonでは変数にデータ型はないが、値にはデータ型ある。データ型（あるいは単に型という）とは、あるデータがどんな値を取りうるか、そしてそのデータに対してどんな操作（演算やメソッド）を行えるかを決めるものだ。

取りうる値が型ごとに決まっているとは、たとえばint型（整数型）は整数の値しか持つことができず、str型（文字列型）はUnicode文字の並びしか値として持てないということである。どんな操作ができるかとは、int型であれば他のint型と加算・減算などの演算ができ、str型では文字列の連結ができるといった具合だ。

* Pythonのデータはすべて「オブジェクト」である
Pythonでは、整数や文字列、リストなど、プログラムが扱うデータはすべてオブジェクトである。ここでいうオブジェクトとはオブジェクト指向プログラミングにおけるオブジェクトのことだ。

オブジェクトはクラスのインスタンスだ。そしてクラスはオブジェクトの定義だ。クラスはオブジェクトの設計図のようなもので、現実の世界で設計図から多くの製品を作り出せるように、1つのクラスから複数のオブジェクトを作成することができる。そして、オブジェクトとは、クラスをもとにメモリ上に作り出された、具体的な実体（インスタンス）にほかならない。クラスからオブジェクトを作成することを特にインスタンス化と呼ぶ。

新しくクラスを定義するという行為は、新しい「型」を生み出す行為でもある。あるクラスのインスタンスであるオブジェクトにとっては、そのクラス自体が自身の型となる。したがって、Pythonでは「型」と「クラス」は同じ意味と考えて良い。クラスについて別の機会に詳しく説明するが、ここでは「型＝クラス」とだけ覚えておけば十分だ。

Pythonでデータ（つまりオブジェクト）の型を調べるには、組み込み関数の type() を使う。

#+begin_src python
>>> type(7)
<class 'int'>
>>> type(3.14)
<class 'float'>
>>> type("abc")
<class 'str'>
>>> type([1, 2, 3])
<class 'list'>
#+end_src

<class 'int'> という表示は、「7はintクラスのインスタンスである」ということを意味している。言い換えれば7はint型（intクラス）のオブジェクトである。

* 基本的な組み込みデータ型
Pythonの基本的な組み込みデータ型を表にまとめると、次のようになる。

| 名前         | 型          | ミュータブル? | リテラルの例        |
|--------------+-------------+---------------+---------------------|
| ブール値     | =bool=      | ×             | =True=, =False=     |
| 整数         | =int=       | ×             | =47=, =25_000=      |
| 浮動小数点数 | =float=     | ×             | =3.14=, =2.7e5=     |
| 複素数       | =complex=   | ×             | =3j=, =5 + 9j=      |
| 文字列       | =str=       | ×             | ='alas'=, ="alack"= |
| リスト       | =list=      | ○             | =['a', 'b', 'c']=   |
| タプル       | =tuple=     | ×             | =(2, 4, 8)=         |

bool・int・floatといった数値型について詳しくは、別の記事で詳しく説明する。「数値型(int・float・bool)の基本をやさしく解説」もあわせて参照してほしい。この記事では、これらの型に共通する「変数」と「代入」の考え方に絞って説明していく。

--------------

* 3. ミュータビリティ:値を変更できる型・できない型
上の表の「ミュータブル?」の列は、そのオブジェクトを*作成したあとで値を書き換えられるかどうか*を示している。

- *イミュータブル(immutable)*:値を変更できない型。int・float・str・tuple・frozensetなど。
- *ミュータブル(mutable)*:値を変更できる型。list・dict・set・bytearrayなど。

* 7. 変数は名前であって場所ではない
変数に値を代入することができるが、値そのものが変数に保存されるわけではない。いくつかのプログラミング言語では変数に値そのものが入っているが、Pythonはそうではない。これはPythonのデータ（値）が、すべてオブジェクトということにも関係している。

例えば次の例では、Pythonのインタプリタが、コードの3という記載を見つけると、3という値を持つint型のオブジェクトをメモリ上のどこかに作成する。そして、foo変数には、メモリ上のどこかにある3という値を持つint型オブジェクトを指し示す値が代入される。

#+begin_src python
>>> foo = 3
#+end_src

つまり、変数の名前はメモリ内のどこかにあるオブジェクトを指し示す「タグ」のようなもので、どんな型のオブジェクトでも指すことができる。値や型を知りたければ、その名前がどのオブジェクトを指しているかを「たどって」いけばよいのだ。

このように変数はオブジェクトを参照していいるといったことを理解しておくことは重要である。例えば次の例を考え見てみよう。

#+begin_src python
>>> a = 7
>>> b = a
#+end_src

ここでは、7という値を変数aに代入し、aの値をさらに変数bへ代入している。先ほどのように詳しく見ていくと、変数aは7という値を持つint型オブジェクトを指している。aの値を変数bに代入することによって、bも同じオブジェクトを指し示すことになる。

変数aと変数bが同じオブジェクトを指していることは、オブジェクトのIDの値を調べることによってわかる。各オブジェクトは一意のID値を持っているので、この値が同じであれば同じオブジェクトである。IDの値は組み込みのid()関数で調べられる。

#+begin_src python
>>> id(a)
4399532024
>>> id(b)
4399532024
#+end_src

int型のオブジェクトはイミュータブルなので、複数の変数が同じオブジェクトを参照していても問題は起きません。しかしミュータブルなオブジェクトは注意が必要です。

次の例は、3つの要素（それぞれの値は1、2、3）を持つリストというオブジェクトをまず変数xに代入しています。そのあとに変数yにxの値を代入しています。これによりxとyは同じリストオブジェクトを参照しています。

#+begin_src python
>>> x = [1, 2, 3]
>>> y = x
>>> x
[1, 2, 3]
>>> y
[1, 2, 3]
#+end_src

リストについては別の機会に説明しますが、ここではリストオブジェクトはミュータブルであることを知っていれば十分です。次にxが参照するリストオブジェクトの最初の要素の値を99に変更しています。

#+begin_src python
>>> x[0] = 99
#+end_src

そうすると、xを通して行われた変更は、yを通しても見ることができます。これはxとyも同じオブジェクトを参照しているからです。

#+begin_src python
>>> x
[99, 2, 3]
>>> y
[99, 2, 3]
#+end_src

イミュータブルなオブジェクト(int・str・tupleなど)なら上のように安心して使えるが、*ミュータブルなオブジェクト(listなど)を複数の名前で共有している場合、片方の名前を通じて値を書き換えると、もう片方の名前で見える値も変わってしまう*。

~b = a~ は値をコピーしているのではなく、=a=と同じリストオブジェクトに=b=という別の名前を貼り付けているだけだ。そのため、=a=を通じてリストの中身を書き換えると、同じオブジェクトを指している=b=から見た値も変わる。値を独立させたコピーが必要な場合は、=list()=や=copy()=、=copy.deepcopy()=などを使う必要がある(リストの章で詳しく扱う)。

他の多くのプログラミング言語では、変数自体が型を持ち、メモリ上の決まった位置に値を書き込む。しかしPythonでは、名前はメモリ内のどこかにあるオブジェクトを指し示す「タグ」のようなもので、どんな型のオブジェクトでも指すことができる。値と型を知りたければ、その名前がどのオブジェクトを指しているかを「たどって」いけばよいのだ。

#+begin_src python
>>> a = 7
>>> b = a
>>> type(a)
<class 'int'>
>>> type(b)
<class 'int'>
#+end_src

** 8.2 名前への再代入
名前はオブジェクトを指しているだけなので、名前に別の値を代入すると、その名前は*新しいオブジェクトを指すように変わるだけ*だ。もとのオブジェクトの値そのものが書き換えられるわけではない。

#+begin_src python
>>> x = 5
>>> y = x
>>> x = 29
>>> x
29
>>> y
5
#+end_src

~y = x~ の時点で、=y=は=x=と同じ「値が5のオブジェクト」を指すようになる。その後 ~x = 29~ としても、=x=が指す先が「値が29の新しいオブジェクト」に変わるだけで、=y=は変わらず5のオブジェクトを指したままだ。

* 9. 適切な変数名の選び方
変数に正しい名前を付けることは、見た目以上に重要だ。学習中は=a=や=x=のような使い捨ての名前を使うことも多いが、実際のプログラムでは同時に管理する変数の数がずっと多くなるため、*簡潔さとわかりやすさのバランス*を意識する必要がある。

たとえば、=number_of_loons=よりも=num_loons=のほうが早くタイピングできるが、=n=よりも=num_loons=のほうが何を表しているかが一目でわかる。Pythonでは、単語をアンダースコアでつなぐ=snake_case=(例:=user_name=、=total_count=)が一般的な命名スタイルだ。
