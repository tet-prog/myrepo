* 【Python入門】辞書（dict）の基本：作成・取得・更新・ループまでやさしく解説
:PROPERTIES:
:CUSTOM_ID: python入門辞書dictの基本作成取得更新ループまでやさしく解説
:END:
リストでは、要素を =[0]=、=[1]= のように *位置（オフセット）* で取り出した。だが、「ユーザー名から電話番号を調べたい」「英単語から日本語訳を引きたい」といった場面では、番号よりも *名前で取り出せる* ほうがずっと便利だ。そんなときに使うのが *辞書（dict）* である。

辞書は、*キー（key）* と *値（value）* をペアにして管理するデータ構造である。この記事では、辞書の作り方から、要素の取得・追加・削除、結合、コピー、ループ、辞書内包表記までをまとめて解説する。

--------------

** この記事でわかること
:PROPERTIES:
:CUSTOM_ID: この記事でわかること
:END:
- 辞書とリストの違い
- ={}= と =dict()= による辞書の作り方
- =[key]= と =get()= による値の取得、=KeyError= の避け方
- =keys()=・=values()=・=items()= の使い方
- 辞書の結合（=update()=・={**a, **b}=・=|= 演算子）
- 要素の削除（=del=・=pop()=・=popitem()=・=clear()=）
- ~=~ による代入と =copy()=・=deepcopy()= の違い
- =for= ループと辞書内包表記

--------------

** 辞書とは
:PROPERTIES:
:CUSTOM_ID: 1-辞書とは
:END:
辞書は、リストと同様に0個以上のデータを保持するデータ型だが、キーと値のペアでデータを保存する。通常はキーを使って値にアクセスする。ほかのプログラミング言語では、連想配列、ハッシュ、ハッシュマップなどと呼ばれることもある。

辞書の特徴は次のとおりである。

- キーと値のペアでデータを保存し、データにアクセスするためにキーを使う。
- キーはユニークでなければならない。値はユニークである必要はない。
- キーはハッシュ可能なオブジェクトである必要がある。値はどのようなオブジェクトでも構わない。
- 辞書はミュータブルである。
- 辞書はキーと値のペアの挿入された順序を保持する。
- キーによる値へのアクセスが速い。


*** 辞書は追加した順番を覚えている
:PROPERTIES:
:CUSTOM_ID: 辞書は追加した順番を覚えている
:END:
Python 3.7以降、辞書は *キーを追加した順番（挿入順序）を保持する* ことが言語仕様として保証されている。=for= ループや =keys()= で取り出すと、追加した順に出てくる。

** 辞書を作成する
:PROPERTIES:
:CUSTOM_ID: 2-辞書の作り方
:END:
*** 辞書リテラル
:PROPERTIES:
:CUSTOM_ID: 辞書リテラル
:END:
リテラル表記で辞書オブジェクトを作成する方法から見ていこう。辞書のリテラル表記には波括弧を使う。「キー: 値」の形式のペアをカンマで区切り、波括弧 ={}= で囲む。何も入れなければ空の辞書になる。

#+begin_src python
>>> empty = {}
>>> empty
{}
>>> fruits = {'apple': 'りんご', 'grape': 'ぶどう', 'peach': 'もも'}
>>> fruits
{'apple': 'りんご', 'grape': 'ぶどう', 'peach': 'もも'}
>>> fruits['grape']
'ぶどう'
#+end_src

最後の要素の後にカンマを残してもかまわない。こうしておくと、最後に要素を追加するときに便利で、カンマのつけ忘れ防止にもなる。

#+begin_src python
>>> weekdays = {
...     'mon': '月曜日',
...     'tue': '火曜日',
...     'wed': '水曜日',
... }
>>> weekdays
{'mon': '月曜日', 'tue': '火曜日', 'wed': '水曜日'}
#+end_src

*** dict()で2要素のシーケンスから変換する
:PROPERTIES:
:CUSTOM_ID: dictで2要素のシーケンスから変換する
:END:
=dict()= には、*「2つの要素を持つシーケンス」を並べたもの* を渡すこともできる。1つ目の要素がキー、2つ目が値になる。

#+begin_src python
>>> pairs1 = [['red', '赤'], ['blue', '青']]   # 2要素のリストのリスト
>>> dict(pairs1)
{'red': '赤', 'blue': '青'}
>>> pairs2 = [('one', 1), ('two', 2)]         # 2要素のタプルのリスト
>>> dict(pairs2)
{'one': 1, 'two': 2}
>>> pairs3 = ['a1', 'b2', 'c3']               # 2文字の文字列のリスト
>>> dict(pairs3)
{'a': '1', 'b': '2', 'c': '3'}
#+end_src

*** zip()と組み合わせる
:PROPERTIES:
:CUSTOM_ID: zipと組み合わせる
:END:
キーのリストと値のリストが別々にあるときは、前回の記事で紹介した =zip()= と組み合わせると便利だ。

#+begin_src python
>>> subjects = ['国語', '数学', '英語']
>>> points = [78, 92, 85]
>>> dict(zip(subjects, points))
{'国語': 78, '数学': 92, '英語': 85}
#+end_src

*** キーにできるもの
:PROPERTIES:
:CUSTOM_ID: キーにできるもの
:END:
キーは文字列が使われることが多いが、*ハッシュ可能なオブジェクト* ならキーとして使うことができる。初めのうちはイミュータブルなオブジェクトがキーとして使えると考えておけば大体間違いではない。一方、値にはどんなオブジェクトでも良い。リストや別の辞書を値にすることもできる。

- 使える：文字列、数値、タプル（要素もすべてイミュータブルな場合）
- 使えない：リスト、辞書など、変更できるオブジェクト

#+begin_src python
>>> points = {(0, 0): 'origin'}        # タプルはキーにできる
#+end_src

#+begin_src python
>>> scores = {'math': 80, 90: 'ninety', (2026, 10): 'year-month'}
>>> scores
{'math': 80, 90: 'ninety', (2026, 10): 'year-month'}
>>> scores[(2026, 10)]
'year-month'
#+end_src

タプル自体はハッシュ可能だが、要素もすべてハッシュ可能である必要がある。

そして、キーはユニークでなければならない。重複したキーを指定した場合は、最後の値が残る。

#+begin_src python
>>> roles = {'leader': 'Sato', 'staff': 'Suzuki', 'staff': 'Tanaka'}
>>> roles
{'leader': 'Sato', 'staff': 'Tanaka'}
#+end_src

** 値を参照する ー [key]とget()
:PROPERTIES:
:CUSTOM_ID: 4-値の取得keyとget
:END:

*** [key]で値を参照する
:PROPERTIES:
:CUSTOM_ID: keyで取り出す
:END:

辞書を使う最も多い理由は、キーを使って素早く値を参照できるからだ。キーで値を参照するには辞書の後ろに続けて角括弧の間にキーを指定する。

#+begin_src python
>>> capitals = {'Japan': 'Tokyo', 'France': 'Paris', 'Italy': 'Rome'}
>>> capitals['Japan']
'Tokyo'
#+end_src

ただし、*存在しないキーを指定すると =KeyError=* になる。

#+begin_src python
>>> capitals['Spain']
Traceback (most recent call last):
  ...
KeyError: 'Spain'
#+end_src

キーが存在するか確証がなければ、事前に =in= でキーが存在することを確認すれば良い。

*** get()で値を参照する
:PROPERTIES:
:CUSTOM_ID: 方法2getを使う
:END:
=get()= は、キーがあればその値を、なければ *第2引数に指定した値（デフォルト値）* を返す。第2引数を省略すると =None= が返る。

#+begin_src python
>>> capitals.get('Japan')
'Tokyo'
>>> capitals.get('Spain', 'Not found')
'Not found'
>>> capitals.get('Spain')          # None が返る（対話モードでは何も表示されない）
>>> print(capitals.get('Spain'))
None
#+end_src
**** コラム：get()で出現回数を数える
:PROPERTIES:
:CUSTOM_ID: コラムgetで出現回数を数える
:END:
=get()= のデフォルト値を使うと、「まだキーがなければ0から数え始める」という処理をすっきり書ける。

#+begin_src python
text = 'mississippi'
counts = {}
for ch in text:
    counts[ch] = counts.get(ch, 0) + 1
print(counts)
#+end_src

#+begin_example
{'m': 1, 'i': 4, 's': 4, 'p': 2}
#+end_example

** 要素の追加・変更：[key] = 値
:PROPERTIES:
:CUSTOM_ID: 3-要素の追加変更key--値
:END:
キーに紐づいた値を変更するには、辞書[キー]で参照してそれに値を代入すれば良い。このとき辞書に存在しないキーを指定すると、キーと値のペアが辞書に追加される。

- キーが *まだない* → 新しいペアとして追加される
- キーが *すでにある* → 値が上書きされる

果物の在庫数を、果物の名前をキー、個数を値にして管理してみよう。

#+begin_src python
>>> stock = {
...     'apple': 12,
...     'banana': 8,
...     'orange': 5,
... }
>>> stock['melon'] = 30     # 追加（個数を間違えた！）
>>> stock['melon']
30
>>> stock['melon'] = 3      # 同じキーに代入すると上書き
>>> stock['melon']
3
>>> stock
{'apple': 12, 'banana': 8, 'orange': 5, 'melon': 3}
#+end_src

=辞書[キー]= で参照するときに *存在しないキーを指定すると =KeyError=* になるが、*存在しないキーへの代入はエラーにならず、追加になる*。

** 値を取り出して削除する — pop()

=pop()= は、キーに対応する値を返し、そのペアを辞書から削除する。

#+begin_src python
>>> menu = {'coffee': 450, 'tea': 400, 'juice': 500}
>>> menu.pop('tea')
400
>>> menu
{'coffee': 450, 'juice': 500}
>>> menu.pop('tea')             # もう存在しない
Traceback (most recent call last):
  ...
KeyError: 'tea'
>>> menu.pop('tea', 0)          # デフォルト値を渡せばエラーにならない
0
#+end_src

*** popitem()：最後に追加したペアを取り出す

=popitem()= は、*最後に追加されたペア* をタプルで返して削除する（Python 3.7以降、後入れ先出しの順が保証されている）。

#+begin_src python
>>> todo = {'laundry': 'morning', 'shopping': 'afternoon', 'cleaning': 'evening'}
>>> todo.popitem()
('cleaning', 'evening')
>>> todo
{'laundry': 'morning', 'shopping': 'afternoon'}
#+end_src

** 要素を削除する

| 方法 | 指定するもの | 戻り値 | キーがないとき |
|---+---+---+---|
| =del 辞書[key]= | キー | なし（文） | =KeyError= |
| =pop(key)= | キー | 削除した値 | =KeyError= |
| =pop(key, デフォルト値)= | キー | 削除した値 | デフォルト値を返す |
| =popitem()= | ― | 最後に追加した =(キー, 値)= | 空なら =KeyError= |
| =clear()= | ― | なし（全削除） | ― |

*** del：キーを指定して削除

#+begin_src python
>>> seats = {'A1': 'Sato', 'A2': 'Suzuki', 'A3': 'Tanaka'}
>>> del seats['A2']
>>> seats
{'A1': 'Sato', 'A3': 'Tanaka'}
#+end_src

*** clear()：すべて削除

#+begin_src python
>>> cart = {'apple': 3, 'milk': 1, 'bread': 2}
>>> cart.clear()
>>> cart
{}
#+end_src

** 辞書を結合する
:PROPERTIES:
:CUSTOM_ID: 6-辞書を結合する
:END:
2つの辞書をまとめる方法はいくつかある。どの方法でも、*同じキーがあった場合は後ろ（右側）の辞書の値が残る*。

*** update()：元の辞書に追加する
:PROPERTIES:
:CUSTOM_ID: update元の辞書に追加する
:END:
=update()= メソッドは、別の辞書のキーと値で *元の辞書を更新* する。元の辞書そのものが変更される。つまり、

- 更新する辞書のキーが、元の辞書に存在すれば更新する辞書の値が上書きされる。
- 元の辞書にキーが存在しなければ、更新する辞書のキーと値のペアが追加される。

#+begin_src python
>>> settings = {'theme': 'light', 'font_size': 12}
>>> changes = {'font_size': 14, 'language': 'ja'}
>>> settings.update(changes)
>>> settings
{'theme': 'light', 'font_size': 14, 'language': 'ja'}
#+end_src

*** {**a, **b}：新しい辞書を作る
:PROPERTIES:
:CUSTOM_ID: a-b新しい辞書を作る
:END:
=**= を使うと、元の辞書を変更せずに、*結合した新しい辞書* を作れる（Python 3.5以降）。3つ以上の辞書も並べられる。

#+begin_src python
>>> defaults = {'theme': 'light', 'font_size': 12}
>>> custom = {'font_size': 16, 'language': 'ja'}
>>> extra = {'autosave': True}
>>> {**defaults, **custom}
{'theme': 'light', 'font_size': 16, 'language': 'ja'}
>>> {**defaults, **extra, **custom}
{'theme': 'light', 'font_size': 16, 'autosave': True, 'language': 'ja'}
#+end_src

*** | と |= 演算子（Python 3.9以降）
:PROPERTIES:
:CUSTOM_ID: -と--演算子python-39以降
:END:
Python 3.9で *~|~ 演算子による辞書の結合* が追加された。これを使えば、=update()= メソッドや ={**a, **b}= と同じようなことができる。

| 書き方        | 元の辞書                 | 対応バージョン |
|---------------+--------------------------+----------------|
| =a.update(b)= | 変更される               | すべて         |
| a \vert{}= b  | 変更される               | 3.9以降        |
| ={**a, **b}=  | 変わらない（新しい辞書） | 3.5以降        |
| a \vert{} b   | 変わらない（新しい辞書） | 3.9以降        |

#+begin_src python
>>> defaults = {'theme': 'light', 'font_size': 12}
>>> custom = {'font_size': 16, 'language': 'ja'}
>>> defaults | custom        # 新しい辞書を作る
{'theme': 'light', 'font_size': 16, 'language': 'ja'}
>>> defaults                 # 元の辞書はそのまま
{'theme': 'light', 'font_size': 12}
>>> defaults |= custom       # 元の辞書を更新する
>>> defaults
{'theme': 'light', 'font_size': 16, 'language': 'ja'}
#+end_src

** inによるキーの存在確認
:PROPERTIES:
:CUSTOM_ID: 方法1inでキーがあるか確かめる
:END:

辞書に特定のキーが存在するか調べるには =in= を使えば良い。

#+begin_src python
>>> 'Japan' in capitals
True
>>> 'Spain' in capitals
False
#+end_src

=in= が調べるのは *キー* である。値が含まれているか調べるには、辞書の =values()= メソッドを使って値の一覧を取得して、それに対して =in= を使う。

#+begin_src python
>>> 'Tokyo' in capitals             # 値を指定しても見つからない
False
>>> 'Tokyo' in capitals.values()    # 値を調べたいときは values() を使う
True
#+end_src

=values()= メソッドは =dict_values= 型のオブジェクトを返すが、これには =in= が使える。

** キー・値・ペアをまとめて取り出す
:PROPERTIES:
:CUSTOM_ID: 5-キー値ペアをまとめて取り出す
:END:
*** keys()・values()・items()
:PROPERTIES:
:CUSTOM_ID: keysvaluesitems
:END:
| メソッド   | 返すもの                       |
|------------+--------------------------------|
| =keys()=   | すべてのキー                   |
| =values()= | すべての値                     |
| =items()=  | すべての =(キー, 値)= のタプル |

#+begin_src python
>>> lang = {'ja': '日本語', 'en': '英語', 'fr': 'フランス語'}
>>> lang.keys()
dict_keys(['ja', 'en', 'fr'])
>>> lang.values()
dict_values(['日本語', '英語', 'フランス語'])
>>> lang.items()
dict_items([('ja', '日本語'), ('en', '英語'), ('fr', 'フランス語')])
#+end_src

戻り値は =dict_keys= などの *ビューオブジェクト* である。リストそのものではないので、リストとして扱いたいときは =list()= で変換する。

#+begin_src python
>>> list(lang.keys())
['ja', 'en', 'fr']
>>> list(lang.values())
['日本語', '英語', 'フランス語']
#+end_src

ビュー(view)は元のデータ（この場合は辞書のデータ）を違う見た目で表しているだけなので、*元の辞書が変わると、ビューの中身も自動的に変わる*。

#+begin_src python
>>> keys = lang.keys()
>>> lang['de'] = 'ドイツ語'
>>> keys
dict_keys(['ja', 'en', 'fr', 'de'])
#+end_src

** 辞書のコピーを作成する
:PROPERTIES:
:CUSTOM_ID: 8-による代入とcopyの違い
:END:
リストと同じく、辞書を ~=~ で別の変数に代入しても *コピーにはならない*。同じ辞書に2つの名前が付くだけなので、片方を変更するともう片方にも影響する。

#+begin_src python
>>> config = {'host': 'localhost', 'port': 8080, 'debug': False}
>>> saved = config
>>> config['debug'] = True
>>> saved
{'host': 'localhost', 'port': 8080, 'debug': True}
#+end_src

*** copy()で独立したコピーを作る
:PROPERTIES:
:CUSTOM_ID: copyで独立したコピーを作る
:END:
#+begin_src python
>>> config = {'host': 'localhost', 'port': 8080, 'debug': False}
>>> backup = config.copy()
>>> config['debug'] = True
>>> backup                    # 影響を受けない
{'host': 'localhost', 'port': 8080, 'debug': False}
#+end_src

*** 値がリストなどのときはdeepcopy()
:PROPERTIES:
:CUSTOM_ID: 値がリストなどのときはdeepcopy
:END:
=copy()= は *浅いコピー* である。値がリストのような変更できるオブジェクトの場合、その中身は共有されたままになる。完全に独立させたいときは =copy= モジュールの =deepcopy()= を使う。

#+begin_src python
>>> import copy
>>> team = {'name': 'Team A', 'members': ['Sato', 'Suzuki']}
>>> shallow = team.copy()
>>> deep = copy.deepcopy(team)
>>> team['members'].append('Tanaka')
>>> shallow['members']        # 内側のリストが共有されている
['Sato', 'Suzuki', 'Tanaka']
>>> deep['members']           # 影響を受けない
['Sato', 'Suzuki']
#+end_src

** 辞書の比較
:PROPERTIES:
:CUSTOM_ID: 9-辞書の比較
:END:
辞書は ~==~ と ~!=~ で比較できる。*キーと値のペアがすべて同じなら等しい* とみなされ、追加した順番は関係ない。

#+begin_src python
>>> a = {'x': 1, 'y': 2, 'z': 3}
>>> b = {'z': 3, 'x': 1, 'y': 2}
>>> a == b
True
#+end_src

一方、~<~ や ~<=~ などの大小比較はできない。

#+begin_src python
>>> a <= b
Traceback (most recent call last):
  ...
TypeError: '<=' not supported between instances of 'dict' and 'dict'
#+end_src

*** キーの順番で並べて取り出す
:PROPERTIES:
:CUSTOM_ID: キーの順番で並べて取り出す
:END:
辞書は追加した順を保持するが、アルファベット順などで処理したいときは =sorted()= を使う。=sorted(辞書)= はキーを並べ替えた *新しいリスト* を返す。

#+begin_src python
>>> ages = {'sato': 28, 'abe': 35, 'kato': 22}
>>> sorted(ages)
['abe', 'kato', 'sato']
#+end_src

#+begin_src python
for name in sorted(ages):
    print(name, ages[name])
#+end_src

#+begin_example
abe 35
kato 22

** 辞書内包表記
:PROPERTIES:
:CUSTOM_ID: 11-辞書内包表記
:END:
リスト内包表記と同じように、辞書にも *辞書内包表記* がある。基本形は次のとおりだ。

#+begin_src python
{キーの式: 値の式 for 変数 in イテラブル}
#+end_src

#+begin_src python
>>> {n: n * 10 for n in (1, 2, 3)}
{1: 10, 2: 20, 3: 30}
#+end_src

=if= を付けて条件で絞り込むこともできる。

#+begin_src python
>>> word = 'alphabet'
>>> vowels = 'aeiou'
>>> {letter: word.count(letter) for letter in word if letter in vowels}
{'a': 2, 'e': 1}
#+end_src

同じ文字が何度も出てくるので、=word.count(letter)= が同じ文字に対して繰り返し実行される。結果は同じ値で上書きされるだけなので問題はないが、無駄を省きたい場合は、『入門Python3』のように =set(word)= で重複を除いた文字だけを回す方法もある（その場合、キーの並び順は実行ごとに変わることがある）。

辞書内包表記は、*既存の辞書を加工する* ときにも便利だ。

#+begin_src python
>>> prices = {'apple': 120, 'banana': 80, 'cherry': 300}
>>> {name: price for name, price in prices.items() if price >= 100}   # 100円以上だけ
{'apple': 120, 'cherry': 300}
>>> {price: name for name, price in prices.items()}                   # キーと値を入れ替え
{120: 'apple', 80: 'banana', 300: 'cherry'}
#+end_src

** 辞書を組み合わせた大きなデータ構造
:PROPERTIES:
:CUSTOM_ID: 12-辞書を組み合わせた大きなデータ構造
:END:
辞書の値にはどんなオブジェクトでも入れられるので、リストや辞書を組み合わせて、より複雑なデータを表現できる。

#+begin_src python
>>> clubs = {
...     'soccer': ['Sato', 'Suzuki'],
...     'tennis': ['Tanaka', 'Ito', 'Kato'],
... }
>>> clubs['tennis'][0]
'Tanaka'
#+end_src

辞書の中に辞書を入れる（入れ子にする）場合は、キーを重ねて取り出す。

#+begin_src python
>>> user = {
...     'name': 'Tanaka',
...     'address': {'city': 'Tokyo', 'zip': '100-0001'},
... }
>>> user['address']['city']
'Tokyo'
#+end_src

また、前回の記事で触れたとおり、*タプルは辞書のキーにできる* ので、座標のような「値の組」をキーにすることもできる。

#+begin_src python
>>> stations = {
...     (35.68, 139.77): 'Tokyo Station',
...     (34.70, 135.50): 'Osaka Station',
... }
>>> stations[(34.70, 135.50)]
'Osaka Station'
#+end_src

** まとめ
:PROPERTIES:
:CUSTOM_ID: まとめ
:END:
- *辞書* は ={キー: 値}= の形でデータを管理する、変更可能なデータ構造
- キーは一意で、文字列・数値・タプルなど *イミュータブルなもの* を使う
- =辞書[key] = 値= で追加・上書き、=辞書[key]= で取得（なければ =KeyError=）
- キーがないかもしれないときは =in= で確かめるか、=get(key, デフォルト値)= を使う
- =keys()=・=values()=・=items()= はビューを返す。リストが欲しいときは =list()= で変換
- 結合は =update()= / ~|=~（元を変更）、={**a, **b}= / ~a | b~（新しい辞書）
- 削除は =del=・=pop()=・=popitem()=・=clear()=
- ~=~ はコピーではない。独立させたいときは =copy()=、値が入れ子なら =deepcopy()=
- =for key, value in 辞書.items():= でキーと値を同時に処理できる
- 辞書内包表記 ={キー: 値 for 変数 in イテラブル if 条件}= で辞書を簡潔に作れる

辞書は、設定値の管理、データの集計、JSONの読み書きなど、実際のプログラムで非常によく使われるデータ構造である。サンプルコードを対話モードで実際に動かして、動きを確かめてみてほしい。次回は、キーだけを集めた辞書のような存在である *集合（set）* を取り上げる予定だ。
