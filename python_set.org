「リストから重複をなくしたい」「2つのグループに共通するものを知りたい」「ある値が含まれているかをすばやく調べたい」――そんなときに活躍するのが *集合（set）* です。

集合は、*同じ値を1つしか持たず、要素に順番がない* データ構造です。この記事では、集合の作り方や要素の追加・削除から、和集合・積集合などの集合演算、集合内包表記、変更できない集合 =frozenset=、実践で役立つ使い方までをまとめて解説します。

本記事は書籍『入門Python3 第2版』8章「辞書と集合」の「8.2 集合」を参考にしつつ、Python公式ドキュメント（Python 3.14）の内容に沿って解説しています。

#+end_quote

* 1. 集合とは？

前回の記事「【Python入門】辞書（dict）の基本」では、キーと値をペアにして管理する辞書を紹介しました。『入門Python3』では、集合は *「バリューを放り出してキーだけを残した辞書のようなもの」* とたとえられています。Python公式ドキュメントのチュートリアルでは、「重複する要素をもたない、順序づけられていない要素の集まり」と説明されています。

集合のおもな特徴は次のとおりです。

| 特徴         | 内容                                                                 |
|--------------+----------------------------------------------------------------------|
| 重複         | 同じ値は *1つだけ* しか入らない                                      |
| 順序         | *ない*（インデックスやスライスで取り出せない）                       |
| 変更         | できる（ミュータブル）。変更できない =frozenset= もある              |
| 入れられる値 | 数値・文字列・タプルなどの *ハッシュ可能* なもの（辞書のキーと同じ） |
| 主な用途     | 重複の除去、値が含まれているかの判定、集合演算                       |

「何かが *あるかどうか* だけわかればよい」ときに使うのが集合です。値に何か情報をひも付けたいときは、辞書を使います。

* 2. 集合の作り方

** {}で作る
要素をカンマで区切り、波括弧 ={}= で囲むと集合になります。

#+begin_src python
>>> even_numbers = {0, 2, 4, 6, 8}
>>> even_numbers
{0, 2, 4, 6, 8}
>>> odd_numbers = {1, 3, 5, 7, 9}
>>> odd_numbers
{1, 3, 5, 7, 9}
#+end_src

同じ値を何度書いても、*重複は自動的に取り除かれます*。

#+begin_src python
>>> basket = {'apple', 'orange', 'apple', 'pear', 'orange', 'banana'}
>>> basket
{'banana', 'pear', 'apple', 'orange'}
>>> len(basket)
4
#+end_src

#+begin_quote
*ポイント*：集合には順序がないため、表示される順番は書いた順番と一致しません。特に文字列の集合は、Pythonを起動するたびに表示順が変わることがあります。この記事の実行結果も一例として見てください。

#+end_quote

順番を持たないので、集合どうしを比べるときも順番は関係ありません。

#+begin_src python
>>> {1, 2, 3} == {3, 2, 1}
True
>>> [1, 2, 3] == [3, 2, 1]   # リストは順番も比べる
False
#+end_src

** 空の集合はset()で作る
ここが初心者のつまずきポイントです。*中身が空の ={}= は、集合ではなく空の辞書になります*。空の集合を作るときは =set()= を使います。

#+begin_src python
>>> empty_set = set()
>>> empty_set
set()
>>> type(empty_set)
<class 'set'>
>>> not_set = {}
>>> type(not_set)
<class 'dict'>
#+end_src

対話モードで空の集合が ={}= ではなく =set()= と表示されるのもこのためです。『入門Python3』によると、辞書のほうが先にPythonに含まれていて、波括弧を自分のものにしていたからだそうです。

** set()で変換する
=set()= にリスト・文字列・タプル・辞書などを渡すと、*重複を取り除いた集合* に変換できます。

#+begin_src python
>>> set('letters')                                          # 文字列 → 1文字ずつ
{'s', 'r', 't', 'e', 'l'}
>>> set(['Dasher', 'Dancer', 'Prancer', 'Mason-Dixon'])     # リスト
{'Prancer', 'Mason-Dixon', 'Dancer', 'Dasher'}
>>> set(('Ummagumma', 'Echoes', 'Atom Heart Mother'))       # タプル
{'Atom Heart Mother', 'Echoes', 'Ummagumma'}
>>> set({'apple': 'red', 'orange': 'orange', 'cherry': 'red'})   # 辞書 → キーだけ
{'apple', 'orange', 'cherry'}
#+end_src

='letters'= には ='e'= と ='t'= が2つずつ含まれていますが、集合では1つずつになっています。辞書を渡した場合は、*キーだけ* が集合の要素になります。

#+begin_quote
*注意*：=set('hello')= は文字列を1文字ずつばらばらにします。='hello'= という文字列そのものを1つの要素にしたいときは ={'hello'}= と書きます。

#+end_quote

#+begin_src python
>>> set('hello')
{'e', 'h', 'l', 'o'}
>>> {'hello'}
{'hello'}
#+end_src

* 3. 要素数の取得と存在チェック
** len()で要素数を数える
#+begin_src python
>>> reindeer = set(['Dasher', 'Dancer', 'Prancer', 'Mason-Dixon'])
>>> len(reindeer)
4
#+end_src

** in／not inで値があるか調べる
『入門Python3』で「集合の用途としてもっとも一般的」とされているのが、=in= による値の有無のテストです。

#+begin_src python
>>> 'Dasher' in reindeer
True
>>> 'Rudolph' in reindeer
False
>>> 'Rudolph' not in reindeer
True
#+end_src

集合は内部でハッシュ値を使って要素を管理しているため、要素がたくさんあっても =in= による判定をすばやく行えます。どれくらい速いのかは、「10. 集合の便利な使い方」で実際に計測してみます。

* 4. 要素の追加と削除
** 追加：add()・update()
1つ追加するときは =add()=、複数をまとめて追加するときは =update()= を使います。すでにある値を追加しても、何も変わりません。

#+begin_src python
>>> s = {1, 2, 3}
>>> s.add(4)
>>> s
{1, 2, 3, 4}
>>> s.add(2)             # すでにある値は増えない
>>> s
{1, 2, 3, 4}
>>> s.update([5, 6, 7])  # イテラブルの要素をまとめて追加
>>> s
{1, 2, 3, 4, 5, 6, 7}
#+end_src

#+begin_quote
*ポイント*：リストの =append()= ではなく =add()= です。集合には順番がないので、「末尾に追加する」という考え方がありません。

#+end_quote

** 削除：remove()・discard()・pop()・clear()
| 方法          | 動き                          | 値がないとき                   |
|---------------+-------------------------------+--------------------------------|
| =remove(値)=  | 指定した値を削除              | =KeyError= になる              |
| =discard(値)= | 指定した値を削除              | 何もしない（エラーにならない） |
| =pop()=       | 任意の要素を1つ取り出して返す | 空の集合なら =KeyError=        |
| =clear()=     | すべての要素を削除            | ―                              |

#+begin_src python
>>> s = {1, 2, 3, 4, 5, 6, 7}
>>> s.remove(3)
>>> s
{1, 2, 4, 5, 6, 7}
>>> s.remove(99)         # 存在しない値
Traceback (most recent call last):
  ...
KeyError: 99
>>> s.discard(99)        # discard()ならエラーにならない
>>> s.discard(7)
>>> s
{1, 2, 4, 5, 6}
>>> s.pop()              # どの要素が取り出されるかは決まっていない
1
>>> s.clear()
>>> s
set()
#+end_src

「値があれば消したい、なければ何もしなくてよい」という場面では =discard()= が便利です。

* 5. forによる反復処理
リストと同じように、=for= で要素を1つずつ取り出せます。

#+begin_src python
furniture = {'sofa', 'ottoman', 'table'}
for piece in furniture:

#+end_src

実行例：

#+begin_example

ottoman
table
#+end_example

ただし、*取り出される順番は決まっていません*。決まった順番で処理したいときは、=sorted()= で並べ替えてからループしましょう。

#+begin_src python
for piece in sorted(furniture):
    print(piece)
#+end_src

#+begin_example

* 6. 集合演算：和・積・差・対称差
集合ならではの機能が、数学の集合と同じような *集合演算* です。まずは ~a = {1, 2}~、~b = {2, 3}~ という2つの集合で試してみましょう。

#+begin_src python
>>> a = {1, 2}
>>> b = {2, 3}
>>> a | b    # 和集合：少なくともどちらかに含まれる
{1, 2, 3}
>>> a & b    # 積集合：両方に含まれる
{2}
>>> a - b    # 差集合：aには含まれるが、bには含まれない
{1}
>>> a ^ b    # 対称差：どちらか一方だけに含まれる
{1, 3}
#+end_src

それぞれの演算には、同じ働きをするメソッドも用意されています。

| 演算   | 演算子   | メソッド                    | 結果に含まれる要素                     |
|--------+----------+-----------------------------+----------------------------------------|
| 和集合 | =a \| b= | =a.union(b)=                | 少なくともどちらかに含まれる要素       |
| 積集合 | =a & b=  | =a.intersection(b)=         | 両方に含まれる要素                     |
| 差集合 | =a - b=  | =a.difference(b)=           | a には含まれるが、b には含まれない要素 |
| 対称差 | =a ^ b=  | =a.symmetric_difference(b)= | どちらか一方だけに含まれる要素         |

#+begin_src python
>>> a.union(b)
{1, 2, 3}
>>> a.intersection(b)
{2}
>>> a.difference(b)
{1}
>>> a.symmetric_difference(b)
{1, 3}
>>> b - a    # 差集合は左右を入れ替えると結果が変わる
{3}
#+end_src

『入門Python3』では、集合演算の中でも群を抜いてよく使われるのは、和集合・積集合・差集合の3つだと紹介されています。

** カクテルの材料で集合演算を体験する
『入門Python3』では、カクテルの名前をキー、材料の集合を値とする辞書 =drinks= を使って集合演算を説明しています。

#+begin_src python
>>> drinks = {
...     'martini': {'vodka', 'vermouth'},
...     'black russian': {'vodka', 'kahlua'},
...     'white russian': {'cream', 'kahlua', 'vodka'},
...     'manhattan': {'rye', 'vermouth', 'bitters'},
...     'screwdriver': {'orange juice', 'vodka'},
... }
#+end_src

まずは =in= を使って、ウォッカ（vodka）が入っているカクテルを探します。

#+begin_src python
>>> for name, contents in drinks.items():
...     if 'vodka' in contents:
...         print(name)
...
martini
black russian
white russian
screwdriver
#+end_src

※ 書籍の実行結果とは表示順が異なりますが、前回の記事で紹介したとおり、Python 3.7以降の辞書はキーを追加した順番で取り出されます。

次は「オレンジジュースかベルモットが入っているカクテル」です。積集合 =&= を使うと簡潔に書けます。

#+begin_src python
>>> for name, contents in drinks.items():
...     if contents & {'vermouth', 'orange juice'}:
...         print(name)
...
martini
manhattan
screwdriver
#+end_src

=&= の結果は、両方に含まれる要素の集合です。どちらも入っていなければ *空の集合 =set()=* になり、=if= の条件では偽（False）として扱われます。

#+begin_src python
>>> drinks['martini'] & {'vermouth', 'orange juice'}
{'vermouth'}
>>> drinks['black russian'] & {'vermouth', 'orange juice'}
set()
#+end_src

「ウォッカは入っているが、クリームもベルモットも入っていない」カクテルは、=not= と組み合わせて探せます。

#+begin_src python
>>> for name, contents in drinks.items():
...     if 'vodka' in contents and not contents & {'vermouth', 'cream'}:
...         print(name)
...
black russian
screwdriver
#+end_src

2種類のルシアン（ブラック・ルシアンとホワイト・ルシアン）の材料も比べてみましょう。

#+begin_src python
>>> bruss = drinks['black russian']
>>> wruss = drinks['white russian']
>>> bruss & wruss     # 共通の材料
{'kahlua', 'vodka'}
>>> bruss | wruss     # どちらかで使う材料すべて
{'kahlua', 'vodka', 'cream'}
>>> wruss - bruss     # ホワイト・ルシアンだけで使う材料
{'cream'}
>>> bruss - wruss     # ブラック・ルシアンだけで使う材料はない
set()
>>> bruss ^ wruss     # どちらか一方だけで使う材料
{'cream'}
#+end_src

** 演算子とメソッドの違い
演算子とメソッドの結果は同じですが、*演算子は両側が集合でないと使えない* のに対して、*メソッドはリストやタプルなど任意のイテラブルを受け取れる* という違いがあります。

#+begin_src python
>>> {1, 2} | [3, 4]
Traceback (most recent call last):
  ...
TypeError: unsupported operand type(s) for |: 'set' and 'list'
>>> {1, 2}.union([3, 4])
{1, 2, 3, 4}
#+end_src

また、=union()=・=intersection()=・=difference()= には、複数の引数をまとめて渡すこともできます。

#+begin_src python
>>> {1, 2}.union([3], (4, 5))
{1, 2, 3, 4, 5}
#+end_src

** 演算結果で元の集合を更新する
=a | b= などの演算は *新しい集合* を返し、元の集合は変わりません。元の集合そのものを書き換えたいときは、次の演算子やメソッドを使います。

| 演算子  | メソッド                           | 動き                                             |
|---------+------------------------------------+--------------------------------------------------|
| ~a \|= b~ | =a.update(b)=                      | b の要素を a に追加する                          |
| ~a &= b~ | =a.intersection_update(b)=         | 両方に含まれる要素だけを a に残す                |
| ~a -= b~ | =a.difference_update(b)=           | b に含まれる要素を a から取り除く                |
| ~a ^= b~ | =a.symmetric_difference_update(b)= | a を、どちらか一方だけに含まれる要素の集合にする |

#+begin_src python
>>> s = {1, 2, 3}
>>> s |= {4, 5}           # s.update({4, 5}) と同じ
>>> s
{1, 2, 3, 4, 5}
>>> s &= {2, 3, 4, 5, 6}  # 共通する要素だけを残す
>>> s
{2, 3, 4, 5}
>>> s -= {2}              # 指定した要素を取り除く
>>> s
{3, 4, 5}
>>> s ^= {5, 6}           # どちらか一方だけにある要素にする
>>> s
{3, 4, 6}
#+end_src

* 7. 部分集合・上位集合の判定
比較演算子やメソッドを使うと、集合どうしの包含関係を調べられます。

| 演算子  | メソッド          | 意味                                                           |
|---------+-------------------+----------------------------------------------------------------|
| ~a <= b~ | =a.issubset(b)=   | a は b の *部分集合*（a の要素がすべて b に含まれる）          |
| =a < b= | ―                 | a は b の *真部分集合*（部分集合で、かつ a と b が等しくない） |
| ~a >= b~ | =a.issuperset(b)= | a は b の *上位集合*（b の要素がすべて a に含まれる）          |
| =a > b= | ―                 | a は b の *真上位集合*（上位集合で、かつ a と b が等しくない） |
| ~a == b~ | ―                 | a と b の要素がまったく同じ                                    |
| ―       | =a.isdisjoint(b)= | a と b に共通の要素が *1つもない*                              |

ブラック・ルシアンにクリームを加えるとホワイト・ルシアンになるので、=bruss= は =wruss= の部分集合です。

#+begin_src python
>>> bruss <= wruss
True
>>> bruss.issubset(wruss)
True
>>> wruss >= bruss
True
>>> bruss <= bruss    # どの集合も自分自身の部分集合
True
>>> bruss < bruss     # 自分自身の真部分集合にはならない
False
#+end_src

=isdisjoint()= を使うと、共通の材料がないかを調べられます。

#+begin_src python
>>> drinks['manhattan'].isdisjoint(drinks['screwdriver'])
True
>>> drinks['martini'].isdisjoint(drinks['manhattan'])   # vermouthが共通
False
#+end_src

#+begin_quote
*注意*：=<= や =>= は *要素数の大小を比べるものではありません*。たとえば ={1, 2}= は ={3, 4, 5}= より要素数が少ないですが、部分集合ではないので ={1, 2} < {3, 4, 5}= は =False= になります。

#+end_quote

#+begin_src python
>>> {1, 2} < {3, 4, 5}
False
#+end_src

* 8. 集合内包表記
リスト内包表記と同じように、集合にも *集合内包表記* があります。角括弧 =[]= の代わりに波括弧 ={}= を使います。

#+begin_src python
{式 for 変数 in イテラブル}
{式 for 変数 in イテラブル if 条件}
#+end_src

#+begin_src python
>>> a_set = {number for number in range(1, 6) if number % 3 == 1}
>>> a_set
{1, 4}
#+end_src

結果は集合なので、重複は自動的に取り除かれます。たとえば「大文字・小文字の違いをそろえてから重複をなくす」といった処理も1行で書けます。

#+begin_src python
>>> words = ['apple', 'Banana', 'APPLE', 'cherry', 'banana']
>>> {word.lower() for word in words}
{'banana', 'apple', 'cherry'}
#+end_src

#+begin_quote
*ポイント*：={キー: 値 for ...}= のようにコロンを使うと、集合ではなく *辞書内包表記* になります。

#+end_quote

* 9. frozenset：変更できない集合
=frozenset()= を使うと、*あとから変更できない（イミュータブルな）集合* を作れます。リストに対するタプルのような存在です。

#+begin_src python
>>> fs = frozenset([3, 2, 1])
>>> fs
frozenset({1, 2, 3})
>>> fs.add(4)
Traceback (most recent call last):
  ...
AttributeError: 'frozenset' object has no attribute 'add'
#+end_src

要素を変更するメソッドは使えませんが、集合演算や =in= による判定は通常の集合と同じように使えます。=set= と =frozenset= を混ぜて演算すると、*左側（第1被演算子）と同じ型* の結果が返ります。

#+begin_src python
>>> fs | {4}
frozenset({1, 2, 3, 4})
>>> {4} | fs
{1, 2, 3, 4}
#+end_src

** frozensetの使いどころ
集合の要素や辞書のキーには、*ハッシュ可能* なもの（数値・文字列・タプルなど）しか使えません。変更できる =set= はハッシュ可能ではないので集合の要素にできませんが、=frozenset= なら使えます。

#+begin_src python
>>> {{1, 2}, {3}}
Traceback (most recent call last):
  ...
TypeError: cannot use 'set' as a set element (unhashable type: 'set')
>>> {frozenset({1, 2}), frozenset({3})}
{frozenset({3}), frozenset({1, 2})}
#+end_src

※ エラーメッセージはPython 3.14のものです。3.13以前では =TypeError: unhashable type: 'set'= と表示されます。

「順番に関係のない組み合わせ」を辞書のキーにしたいときにも便利です。

#+begin_src python
>>> recipes = {frozenset({'vodka', 'kahlua'}): 'black russian'}
>>> recipes[frozenset({'kahlua', 'vodka'})]   # 書く順番が違っても取り出せる
'black russian'
#+end_src

* 10. 集合の便利な使い方
** リストの重複を取り除く
リストを =set()= で集合に変換すると、重複を簡単に取り除けます。ただし、*元の順番は失われます*。

#+begin_src python
>>> tags = ['python', 'set', 'python', 'beginner', 'set']
>>> set(tags)
{'python', 'beginner', 'set'}
>>> sorted(set(tags))            # 重複を除いて並べ替える
['beginner', 'python', 'set']
>>> list(dict.fromkeys(tags))    # 最初に出てきた順番を保つ
['python', 'set', 'beginner']
#+end_src

元の順番を保ちたいときは、=dict.fromkeys()= で辞書のキーにしてからリストに戻す方法がよく使われます。Python 3.7以降の辞書は、キーを追加した順番を保つためです。

** たくさんのデータの存在チェックを速くする
リストの =in= は、要素を先頭から順番に比べていきます。一方、集合はハッシュ値を使って目的の値を探すため、要素の数が多いほど大きな差が出ます。標準ライブラリの =timeit= で計測してみましょう。

#+begin_src python
from timeit import timeit

numbers_list = list(range(100_000))   # 0〜99999のリスト
numbers_set = set(numbers_list)       # 同じ内容の集合

# 99999が含まれているかを1000回調べるのにかかった時間（秒）
print(timeit('99_999 in numbers_list', globals=globals(), number=1000))
print(timeit('99_999 in numbers_set', globals=globals(), number=1000))
#+end_src

実行例：

#+begin_example
0.6702464760000453
2.793800001654745e-05
#+end_example

※ 実行時間は環境によって異なります。=timeit()= は、文字列で渡したコードを =number= 回実行して、かかった時間（秒）を返します。~globals=globals()~ は、作った変数をそのコードの中で使えるようにする指定です。=timeit= の詳しい使い方は『入門Python3』19章で解説されています。

この例では、集合のほうが1万倍以上速くなりました。同じデータに対して何度も =in= で調べる場合は、あらかじめ集合に変換しておくと効果的です。

** 2つのデータの差分を調べる
先月と今月の会員名簿を比べて、継続・新規・退会の会員を調べてみましょう。

#+begin_src python
last_month = {'sato', 'suzuki', 'takahashi', 'tanaka'}
this_month = {'suzuki', 'takahashi', 'ito', 'watanabe'}

print('継続:', sorted(last_month & this_month))
print('新規:', sorted(this_month - last_month))
print('退会:', sorted(last_month - this_month))
#+end_src

実行結果：

#+begin_example
継続: ['suzuki', 'takahashi']
新規: ['ito', 'watanabe']
退会: ['sato', 'tanaka']
#+end_example

=for= と =if= で書くと何行もかかる処理が、集合演算ならそれぞれ1行で書けます。表示の順番をそろえるために =sorted()= を使っています。

* 11. よくあるミスと注意点
** ① {}で空の集合を作ろうとする
={}= は空の *辞書* です。空の集合は =set()= で作ります。

** ② インデックスで要素を取り出そうとする
集合には順番がないので、=[0]= のようなインデックスやスライスは使えません。

#+begin_src python
>>> marx_set = {'Groucho', 'Chico', 'Harpo'}
>>> marx_set[0]
Traceback (most recent call last):
  ...
TypeError: 'set' object is not subscriptable
#+end_src

順番に扱いたいときは、=sorted()= で並べ替えたリストに変換してから使いましょう。

** ③ リストや辞書を要素にしようとする
集合の要素にできるのはハッシュ可能なものだけです。リスト・辞書・集合は要素にできません。複数の値の組を入れたいときは、タプルにしましょう。

#+begin_src python
>>> {[1, 2], [3, 4]}
Traceback (most recent call last):
  ...
TypeError: cannot use 'list' as a set element (unhashable type: 'list')
>>> {(1, 2), (3, 4)}
{(1, 2), (3, 4)}
#+end_src

※ エラーメッセージはPython 3.14のものです。3.13以前では =TypeError: unhashable type: 'list'= と表示されます。また、タプルでも中にリストを含む場合は要素にできません。

** ④ remove()で存在しない値を削除しようとする
=remove()= は、値がないと =KeyError= になります。値がないかもしれない場合は、=discard()= を使うか、=in= で確認してから削除します。

** ⑤ 集合にしたら順番がばらばらになった
=set()= で重複を取り除くと、元の順番は保たれません。順番が必要なら =sorted()= で並べ替えるか、=list(dict.fromkeys(リスト))= を使いましょう。

* 12. リスト・タプル・辞書・集合の使い分け
これまでに登場したデータ構造をまとめておきます。

|                | リスト       | タプル       | 辞書               | 集合                             |
|----------------+--------------+--------------+--------------------+----------------------------------|
| 書き方         | =[1, 2, 3]=  | =(1, 2, 3)=  | ={'a': 1, 'b': 2}= | ={1, 2, 3}=                      |
| 空の作り方     | =[]=         | =()=         | ={}=               | =set()=                          |
| 変更           | できる       | できない     | できる             | できる（=frozenset= はできない） |
| 順序           | あり         | あり         | あり（追加した順） | *なし*                           |
| 同じ値の重複   | できる       | できる       | キーは重複できない | *できない*                       |
| 要素の取り出し | インデックス | インデックス | キー               | できない（=in= で有無を調べる）  |

『入門Python3』でも、リスト・タプル・辞書は角括弧で1つの要素を取り出せるのに対して、集合は「あるかないかがわかるだけ」と説明されています。

#+begin_src python
>>> marx_list = ['Groucho', 'Chico', 'Harpo']
>>> marx_tuple = ('Groucho', 'Chico', 'Harpo')
>>> marx_dict = {'Groucho': 'banjo', 'Chico': 'piano', 'Harpo': 'harp'}
>>> marx_set = {'Groucho', 'Chico', 'Harpo'}
>>> marx_list[2]
'Harpo'
>>> marx_tuple[2]
'Harpo'
>>> marx_dict['Harpo']
'harp'
>>> 'Harpo' in marx_set
True
#+end_src

使い分けの目安は次のとおりです。

| 使う場面                                       | おすすめ |
|------------------------------------------------+----------|
| 順番どおりに並べて、追加・削除・並べ替えをする | リスト   |
| 変わらない値の組（座標、年月日など）           | タプル   |
| キーを使って値を取り出す                       | 辞書     |
| 重複をなくしたい                               | 集合     |
| 値が含まれているかを何度も調べる               | 集合     |
| 共通部分や差分を求めたい                       | 集合     |

--------------

* まとめ
- *集合（set）* は、重複しない・順序がない要素の集まり
- ={1, 2, 3}= や =set()= で作る。*空の集合は =set()=*（={}= は空の辞書）
- =set()= にリストなどを渡すと、重複を取り除いた集合に変換できる
- 追加は =add()=・=update()=、削除は =remove()=・=discard()=・=pop()=・=clear()=
- =in= による存在チェックが得意で、要素が多くても高速
- 和集合 =|=、積集合 =&=、差集合 =-=、対称差 =^= で集合演算ができる
- ~<=~・~>=~ などで部分集合・上位集合を判定できる
- 集合内包表記 ={式 for 変数 in イテラブル if 条件}= で集合を簡潔に作れる
- 変更できない集合 =frozenset= は、集合の要素や辞書のキーにできる

集合は「重複をなくす」「含まれているかを調べる」「共通点や差分を求める」といった日常的な処理を、とてもシンプルにしてくれるデータ構造です。サンプルコードを対話モードで実際に動かして、動きを確かめてみてください。次回は、処理をひとまとめにして何度も使えるようにする *関数* を取り上げる予定です。
